# Roadmap: October 2026 through October 2027

- October–December 2026: maintain stable source/package compatibility, improve private reporting and resolve input-validation and dependency findings with synthetic regressions.
- January–April 2027: expand evidence-contract tests for interrupted sessions, stale observations, adapter changes and inconsistent producer/consumer clocks; review upgrade documentation.
- May–October 2027: review supported Python and capture dependencies, measure coverage across source and delivery helpers, and assess the maintenance/release recovery arrangement.

Priorities are discussed in public issues and may change with evidence. This roadmap does not promise sensor accuracy, physical-device certification, safety-critical operation, unattended device control or complete proof of third-party code. A stable release remains software qualification, not independent sensing validation. There is currently no designated backup maintainer; assigning one is not a delivered feature.
